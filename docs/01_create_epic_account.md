# Step 1 — Create Epic Developer Account

To start integrating with Epic FHIR APIs, you must first create a developer account.

Epic provides a sandbox environment for testing through the Epic on FHIR Developer Portal.

Portal:
https://fhir.epic.com/

Steps

1. Go to https://fhir.epic.com/
2. Click "Sign Up"
3. Create a developer account
4. Verify your email
5. Login to the developer dashboard

Once logged in you will be able to:

- Explore Epic FHIR APIs
- Register applications
- Access sandbox environments
- Test API calls

Next Step:
Go to Step 2 → Register Epic Application
